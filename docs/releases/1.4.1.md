## New

- **A setup card on first launch.** Recordings shows a short checklist the first time you open
  Earshot: allow the microphone, and allow Accessibility so dictation can type for you (or choose
  **Not Now**). Each step has its own button, and the card goes away once both are done.

## Fixed

- **The Accessibility prompt no longer reopens on every dictation.** Earshot asks at most once per
  launch. If it isn't allowed yet, dictation puts the
  text on the clipboard so nothing is lost.
- **Reset and allow works in one go.** After resetting the Accessibility permission, Earshot restarts
  itself so it appears in System Settings → Privacy & Security → Accessibility, ready to switch on.

Your recordings, notes, models, settings and permissions stay as they are.

## Install or update

With Homebrew: `brew upgrade --cask earshot`.

Or download **Earshot-1.4.1.dmg** below, open it, and drag **Earshot** onto **Applications**. Choose
**Replace** if it asks.

Check the version under **Earshot → About Earshot**. It should read `1.4.1`.

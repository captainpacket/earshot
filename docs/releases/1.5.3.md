## Fixed

- **The window no longer slides up under the title bar.** While the "Set up Earshot" card showed (on
  first launch, or until Earshot is allowed to type for dictation), or while the speech models were
  downloading, the whole window was drawn too high. The sidebar's top items and the search field were
  cut off, and the window buttons sat on top of the sidebar. The setup cards now scroll with the Home
  list, so the window always fits.

## Install or update

With Homebrew: `brew upgrade --cask earshot`.

Or download **Earshot-1.5.3.dmg** below, open it, and drag **Earshot** onto **Applications**. Choose
**Replace** if it asks.

Check the version under **Earshot → About Earshot**. It should read `1.5.3`.

## New

- **Opens with a double-click.** Earshot is now signed with a Developer ID and notarized by Apple, so
  macOS opens the disk image and the app without the **Open Anyway** detour in System Settings.
- **The models download inside the app.** There are no more Terminal commands to paste. The first time
  you open Earshot, a card offers the speech and speaker models (1.7 GB, once), shows progress, and can
  be cancelled or tried again. Each file is checked against its published fingerprint before Earshot
  uses it. Translate's model (1.1 GB) is offered the first time you turn Translate on. Models you
  already downloaded the old way are recognized, and nothing downloads again.
- **No Homebrew needed.** Earshot now carries its own transcription engine, its own audio converter and
  a native speaker detector, so installing needs nothing else, and labelling speakers no longer
  downloads anything the first time it runs. Ogg and WebM files, which macOS itself can't
  read, still need ffmpeg (`brew install ffmpeg`).
- **Install and update with Homebrew, if you like.** `brew tap gaberger/earshot` and then
  `brew install --cask earshot`. Updates come with `brew upgrade`.

## Changed

- **Earshot has a new app identity, `org.sticksandstrings.earshot`.** Your settings carry over by
  themselves. macOS treats the app as new, though, so it asks for the **Microphone** and
  **Accessibility** permissions once more. Allow both, and Recording and Dictation work as before.

Your recordings, summaries and notes are unchanged.

## Install or update

Download **Earshot-1.3.0.dmg** below, open it, and drag **Earshot** onto **Applications**.
Choose **Replace** if it asks. Open Earshot, then allow the Microphone and, for Dictation, the
Accessibility permission when macOS asks. If Dictation does not type, switch Earshot on in
**System Settings → Privacy & Security → Accessibility**; an old **Earshot** entry left there from
1.2.1 can be removed.

With Homebrew: `brew tap gaberger/earshot && brew install --cask earshot`. If Homebrew says the tap is
not trusted, run `brew trust --tap gaberger/earshot` and try again.

Check the version under **Earshot → About Earshot**. It should read `1.3.0`.
